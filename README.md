# TaskTrack

TaskTrack is a command-line task manager created for CPS 310.

## Current Features

-View Tasks that have been created 
-Add tasks to your list to be viewed

## Requirements

-Python 3

## Project Files

-`tasktrack.py` — main file running the code for the menu 
-`tasks.txt` — saves our tasks that we input into the menu 
-`.gitignore` — ignores certain things or files inside of our project

## Running the Program

in order to ru this task you need to open terminal and run python tasktrack.py

## Task Persistence

tasks are loaded from tasks.txt and saved from the menu when put into the menu and stored inside of tasks.txt


## Current Limitation

when prompted to close the program with 3 the menu will display a goodbye message confirming that you have terminated the program.
