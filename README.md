# TaskTrack

TaskTrack is a command-line task manager created for CPS 310.

## Current Features

-View Tasks that have been created 
-Add tasks to your list to be viewed

## Running the Program

in order to ru this task you need to open terminal and run python tasktrack.py

## Current Limitation

when prompted to close the program with 3 the menu will display a goodbye message confirming that you have terminated the program.

## Version Control

This project uses Git for local version control to track code changes and manage the development history. 

GitHub serves as the remote repository hosting the project online, enabling cloud backup and collaboration.

When working on TaskTrackClone you have to save your local snapshots by making a commit. You can synchronize your local changes with GitHub and push your commits to the remote repository. Before starting new work, perform a pull to fetch and merge the latest changes from GitHub into your local workspace.
