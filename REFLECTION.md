# ICA04 Reflection

## 1. Local and Remote Repositories

The local TaskTrack repository is your personal offline workspace on your computer while the GitHub repository is the online cloud backup that hosts and syncs those changes for remote storage and collaboration

## 2. Connecting and Pushing

Adding origin only creates a shortcut linking your computer to the remote repository URL so your files aren't uploaded until you actually run the git push command to send them over

## 3. Cloning

Cloning creates a full Git repository containing the complete commit history and remote link for tracking future changes but downloading a ZIP only extracts a static snapshot of the current files without any version control features

## 4. Fetching and Pulling

git fetch updated your local tracking branches with the latest history from GitHub without altering your working files while git pull took the additional step of automatically merging those remote changes directly into your active local workspace

## 5. Focused Commits

Committing them separately creates a organized history that makes specific changes easier to review, track down, or undo without affecting unrelated parts of the project
